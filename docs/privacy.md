# Privacy Policy

Last updated: September 2026

## 1. Introduction

This Privacy Policy explains what information the Discord bot collects, how it is used, and how it is stored.

The bot is a personal programming project created for learning and development purposes.

## 2. Information Stored

The bot stores the following information when moderation warnings are issued:

- Discord user ID
- Warning reason

The bot does not intentionally collect passwords, Discord tokens, payment information, or other sensitive personal information.

## 3. How the Information Is Used

The stored information is used only for the bot's moderation system.

Warning information is used to:

- Keep track of a user's warnings
- Display warning history through the `/warnings` command
- Automatically kick a user after reaching 3 warnings

## 4. Data Storage

Warning information is stored locally in an SQLite database used by the bot.

The database is not included in the project's public GitHub repository.

The Discord bot token is stored separately in an environment variable and is not included in the public repository.

## 5. Data Sharing

The stored warning information is not intentionally sold or shared with third parties.

## 6. Data Retention

Warning records may remain stored in the bot's database for moderation history purposes.

The developer may delete or modify stored warning records when necessary.

## 7. Discord

This bot operates through Discord and is subject to Discord's own Terms of Service and Privacy Policy.

The bot does not replace or modify Discord's privacy practices.

## 8. Changes to This Privacy Policy

This Privacy Policy may be updated when necessary.

Any changes will be published on this page.

## 9. Contact

For questions regarding this Privacy Policy, please contact the developer through the project's GitHub repository.
